============================================================
  LiciteAgora Electron Browser — Teste de hCaptcha
============================================================

OBJETIVO:
  Testar se o hCaptcha passa automaticamente (invisible)
  quando rodando de um IP residencial vs IP de datacenter.

REQUISITOS:
  - Node.js 18+ instalado (https://nodejs.org)
  - Windows 10/11, macOS ou Linux com interface grafica

============================================================
  INSTALACAO (rodar no terminal/cmd)
============================================================

  1. Copiar esta pasta para seu computador

  2. Abrir terminal na pasta e instalar:
     npm install

  3. Executar:
     npm start

============================================================
  MODO MULTI-PORTAL (--portal, 2026-05-15)
============================================================

  O mesmo binario suporta 2 portais via flag --portal:

    --portal=comprasnet   (DEFAULT, comportamento historico)
                          Loga via gov.br SSO + captura Bearer
                          Profile: .electron-profile

    --portal=bnc          BNC Compras (bnccompras.com)
                          Loga via teclado virtual + reCAPTCHA v3
                          Profile: .electron-profile-bnc
                          Usa partition persist:bnc no <webview>
                          Sincroniza cookies (nao Bearer) ao servidor

  Exemplos:
    npm start
    electron --no-sandbox electron-browser.js --portal=bnc

  No build Windows, criar 2 atalhos no Desktop apontando pro mesmo
  .exe com argumentos diferentes:
    "LiciteAgora Browser"   -> LiciteAgora-Browser.exe
    "LiciteAgora BNC"       -> LiciteAgora-Browser.exe --portal=bnc

  Os dois podem rodar SIMULTANEAMENTE — single-instance lock e
  por portal (app.setName diferente: "LiciteAgora Browser" e
  "LiciteAgora BNC"). Profile dirs separados garantem cookies
  isolados.

  REPLACEMENT do app antigo "LiciteAgora-BNC-Setup.exe":
  o binario unificado substitui o app BNC separado de
  electron-bnc/. Veja electron-bnc/DEPRECATED.md para detalhes
  da migracao.

============================================================
  CONFIGURACAO INICIAL (multi-tenant, 2026-04-22)
============================================================

  Na primeira execucao, o Electron abre um dialog pedindo:

    - Subdominio ou URL completa
      ex: "1bit"  ou  "https://1bit.liciteagora.app"

    - API Key do tenant
      voce recebe essa chave ao criar o tenant no painel
      admin (https://admin.liciteagora.app)

  A config fica salva em .electron-profile/liciteagora-config.json
  e e reutilizada nas proximas execucoes.

  Para automatizar (skip do dialog):

    - Via argumentos:
      electron . --server-url 1bit.liciteagora.app --api-key ABC...

    - Via env vars:
      LICITEAGORA_SERVER_URL=1bit.liciteagora.app
      LICITEAGORA_API_KEY=ABC...

============================================================
  O QUE VAI ACONTECER
============================================================

  - Abre uma janela de navegador (Chromium/Electron)
  - Navega automaticamente para o portal Comprasnet
  - Voce pode navegar manualmente pela barra de URL

============================================================
  TESTE DO hCAPTCHA
============================================================

  TESTE MANUAL (mais simples):
    1. Na barra de URL, va para:
       https://comprasnet.gov.br/seguro/loginPortal.asp
    2. Clique "Fornecedor Brasileiro"
    3. Clique "Entrar com Gov.br"
    4. Digite seu CPF e clique "Continuar"
    5. OBSERVE: o hCaptcha aparece como challenge visual
       (selecionar imagens) ou passa automaticamente?

  TESTE VIA API (automatizado):
    Com o Electron aberto, abra OUTRO terminal e execute:

    curl -X POST http://localhost:9500/login ^
      -H "Content-Type: application/json" ^
      -d "{\"cpf\":\"SEU_CPF_AQUI\",\"senha\":\"SUA_SENHA\"}"

    Acompanhe o progresso:
    curl http://localhost:9500/status

============================================================
  RESULTADOS ESPERADOS
============================================================

  SE hCaptcha PASSAR AUTOMATICO (sem challenge visual):
    -> Problema confirmado: IP do servidor esta sendo
       bloqueado pelo hCaptcha. Solucao: proxy residencial
       ou AntiCaptcha.

  SE hCaptcha MOSTRAR CHALLENGE (selecionar imagens):
    -> Problema NAO e so o IP. O hCaptcha detecta algo
       no Electron tambem. Solucao: AntiCaptcha.

============================================================
  ENDPOINTS DA API LOCAL (porta 9500)
============================================================

  GET  /status     — estado da sessao
  GET  /bearer     — token atual
  GET  /api-log    — ultimas requisicoes
  POST /login      — login automatico {cpf, senha}
  POST /navigate   — navegar para URL {url}
  POST /fetch      — executar fetch no contexto do browser
  POST /exec       — executar JS no webview {js}
  POST /reload     — recarregar pagina

============================================================
  NOTAS
============================================================

  - O Electron roda como Chromium REAL (nao headless)
  - Sem navigator.webdriver, sem flags de automacao
  - Perfil persistente em .electron-profile/ (Comprasnet)
                       ou .electron-profile-bnc/ (BNC)
  - Se fechar e abrir de novo, cookies sao mantidos
  - Bearer token e capturado automaticamente quando logado (Comprasnet)
  - Cookie sincronizado ao servidor automaticamente (BNC)
  - Keepalive automatico a cada 60s apos login (Comprasnet)
