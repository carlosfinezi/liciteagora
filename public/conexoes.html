Teste Funcional — Envio de Proposta

Para validar o sistema de ponta a ponta (sniper de lances e monitor de chat), este teste envia uma proposta real em uma compra do Comprasnet. Atenção: isso cria uma participação real na compra informada. Use uma compra de teste ou uma onde você já participa.

1️⃣
Informar CompraId
Informe o ID da compra para testar. Deve ser uma compra em fase de propostas.
2️⃣
Verificar Itens da Compra
Busca os itens disponíveis na compra para selecionar qual enviar proposta.
3️⃣
Enviar Proposta de Teste
Envia uma proposta no item selecionado com valor alto (não competitivo, apenas para validação).
