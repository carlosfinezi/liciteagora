🔐 Electron · API Key deste tenant

Esta chave identifica o Electron standalone como pertencente a este tenant. Informe no setup dialog na primeira execução do Electron, junto com o subdomínio 1bit.

⚠️ Ao gerar uma chave nova, o Electron que está instalado com a chave antiga será desconectado. Você precisará abrir o setup dialog dele e colar a nova.

⬇️ Baixar Electron (Windows) LiciteAgora-Setup.exe — instalador recomendado (atalho + inicialização automática)
