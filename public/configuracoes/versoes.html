LiciteAgora Electron

Windows x64

Browser dedicado para Comprasnet. Faz login automatico via Gov.br, captura Bearer token, sincroniza com o servidor (participacoes, mensagens, disputas) e processa fila de lances.

Funcionalidades: Auto-login, keepalive, retoken, sync a cada 2 min, lances automaticos
Download ZIP
Instalacao: Extraia o ZIP, execute LiciteAgora Browser.exe. Para auto-start no login, execute instalar-servico.bat como Administrador.
