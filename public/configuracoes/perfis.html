Perfis de Acesso

O perfil define quais páginas o usuário abre
O perfil admin é fixo, abre tudo e não pode ser limitado — é onde ficam os administradores. Qualquer outro perfil só passa a restringir depois de cadastrado aqui; enquanto não existir cadastro para ele, quem o usa continua vendo o sistema inteiro. A restrição vale para as páginas e para as funções que elas usam: uma tela fora do perfil não abre, e os dados dela também não respondem por outro caminho. Telas de detalhe (ex.: um pedido dentro de Comercial) acompanham o acesso à listagem do mesmo módulo.
